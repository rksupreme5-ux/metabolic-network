# Metabolic Precursors & Amino Acids Network

An interactive, force-directed graph built with [D3.js](https://d3js.org/). This project visualizes the hierarchical network mapping 6 central metabolic precursors to the 20 amino acids they generate, grouped by their core biochemical pathways (Citric Acid Cycle, Glycolysis, Pentose Phosphate Pathway).

## Features
* **Force-Directed Physics:** Nodes naturally repel each other while connected nodes are pulled together.
* **Interactive Dragging:** Click and drag any node to manipulate the network layout in real-time.
* **Highlight Connections:** Hover over any node to instantly fade out unrelated pathways and highlight immediate connections.

## How to Run Locally
1. Clone the repository: `git clone https://github.com/yourusername/metabolic-network.git`
2. Open the directory.
3. Double-click `index.html` to open it in any modern web browser. No local server or build tools are required.
